# 推幣軍團（COINFRONT）

上推幣、下打怪的桌面優先可玩 Demo。這是以 Steam（先做 Windows）為長遠目標的專案 **里程碑 1**：先把核心循環做成用瀏覽器就能打開的靜態遊戲，之後再打包成桌面版。

工作標題：**推幣軍團**；英文副標 **COINFRONT**。

公開 Demo：https://eric52145.github.io/coinfront/

## 點樣喺本機打開

唔使安裝、唔使編譯。用瀏覽器打開專案根目錄嘅 `index.html` 即可，例如：

- 檔案總管雙擊 `index.html`
- 或喺專案目錄執行：`python3 -m http.server 8080`，再用瀏覽器開 `http://localhost:8080/`

建議用桌面視窗（約 1280 寬或以上，例如 1440×900）。寬螢幕會同時睇到上方較扁嘅推幣盤同下方較大嘅軍團戰場。桌面背景係為橫向舞台重繪嘅像素圖（木紋、草地同城牆用鋪貼，唔會拉闊手機原圖）。戰場係垂直進場：上方係我方 2–3 排全闊防線（城牆做後方背景），敵軍由下方湧上。闊度 ≤820px 嘅手機瀏覽器改用直向機台排法，但用同一套垂直戰場方向，等比例裁切，唔會壓扁精靈。

## 點玩

唯一操作係 **喺推幣機落幣同瞄準**。下方戰場係結果同表演，唔使另設陣形或撳「出陣」。

1. 點擊、拖曳畫布，或撳空白鍵投幣。左右方向鍵（或 A / D）可以左右瞄準。
2. 推進板會把盤面硬幣推向前。跌出底邊並且落入中間接幣區，就會喺戰場生效；左右漏口會漏幣。底邊移動嘅 **x2 黃金門**會令該枚效果加倍。
3. 幣由推盤前緣跌入場，彈地一兩下，**落地後**先生效：**兵幣**喺落點召喚士兵；**金幣**獲得 $6；若穿過黃金門則獲得 $12，並額外 +1 投幣額度。
4. ☄️ 隕石、❄️ 暴風雪、⚡ 號角係地圖砲／全軍技能幣。
5. 2.8 秒內連續跌落同類型兵幣會合成 2★／3★。軍團滿員（40）後再召兵，會為場上優先同類型嘅士兵升星，唔會默默刪兵。
6. 拍機台能量滿格時可撳「拍機台」（或 S 鍵），將盤面硬幣一齊推落。
7. 守住一波後，己方士兵基本留守（2★／3★ 必定留，1★ 亦留），另有過關賞金；只有軍團超過人口上限時，多餘嘅 1★ 先會溫和整編換少量金幣。然後 3 選 1 升級（幣袋／推盤／軍團／經濟等不同選擇），並補充 +6 投幣，再有約 3 秒整軍。戰役結構到第 12 波為一個段落（可繼續無盡），每 3 波換一種 BOSS。商店可買兵幣、大招幣、補幣，亦可花 $8 刷新貨單。右上「營地」係可選局外成長：打得越遠，下一局開場稍豐，唔會鎖內容。空白鍵投幣有短間隔，瞄準柱會對應戰場落點。

暫停：P 鍵。玩法說明：右上「?」。

## 核心循環（幾句）

投幣 → 推盤把幣推落 → 落地變成大軍或地圖砲 → 自動同湧入嘅敵潮打仗 → 過關揀強化、補給再爬下一波。爽感來自每一口投幣都即時改局面，而唔係分開管理另一場戰鬥。

## 里程碑 1 範圍

- 可玩桌面 Demo（靜態 HTML / CSS / JS）
- 規則說明同程式實際效果一致
- 以完整可玩一局為方向：我方上限 40，敵軍同時最多約 100；第 1 波 40 隻，之後 28+波×12；12 波戰役＋無盡；更多兵種／敵種／BOSS 與 3 選 1、營地進度
- 未包含 Steam 包裝、成就、存檔雲、安裝程式或付費系統。呢個 Demo **唔涉及真實賭博或下注**。
