# 珠落出陣 Beadfall

手機優先嘅轉珠爬塔小遊戲 demo。純 HTML / CSS / JS，無需安裝或編譯。

## 點樣開

- **線上：** [https://eric52145.github.io/bead-fall/](https://eric52145.github.io/bead-fall/)
- **本機：** 用瀏覽器直接打開 `bead-fall/index.html`（或任意靜態伺服器指向呢個資料夾）

建議用手機直向，或桌面瀏覽器縮到約 390×844 預覽。

## 點玩

1. 撳「轉」——輪盤同珍珠會反向旋轉（賭場輪盤感），珠落入格就出怪（或觸發回復泉）。
2. 相同怪獸、相同星級會自動合成（兩隻 1★ → 一隻 2★，上限 3★）。
3. 名冊最多 6 隻；塞唔落又合唔成時，會變成小回復。
4. 有至少一隻怪就可以撳「出陣」打呢一層（剩餘轉數可先用完）。
5. 贏咗揀三選一獎勵，強化輪盤或轉數，然後繼續爬樓。
6. 全軍覆沒就完局，可「再來一局」。最佳層數會記喺本機。

開場提示：**轉珠出怪，合成變強，出陣打關**

## 規則摘要

| 項目 | 說明 |
|------|------|
| 每層轉數 | 預設 5（可用獎勵增加） |
| 起始輪盤 | 盾石×2、焰狼×2、潮鴉、葉鹿、雷鷲、回復泉 |
| 合成 | 同怪同星自動合；上限 3★ |
| 名冊 | 上限 6；溢出 → 小回復 |
| 陣型 | 盾戰士前排、近戰中排、法師／補師後排 |
| 首領 | 每 5 層一場較強小首領 |
| 獎勵 | 改輪盤／轉數／隊伍屬性，唔係貨幣 |

## 檔案

- `index.html` — 頁面結構
- `styles.css` — 深色街機／寶石盤風格
- `game.js` — 遊戲邏輯
- `art/` — 角色立繪 JPEG（輪盤／名冊／戰鬥用）
- `TASK.md` — 開發任務清單
