# 行情出陣 Ticker Beasts

用瀏覽器打開 `index.html`，或在本資料夾開一個靜態伺服器（例如 `python3 -m http.server 8766`），然後前往對應網址。

開局有 $1,000。先喺建倉階段用凍結緊嘅開市報價買好第一批，再撳「確認開市」。確認之後，行情先會自己行：大約每 5 秒跳一次價，每隔約 30 至 60 秒會有頭條（大或小）帶動板塊。每個板塊有兩隻性格唔同嘅虛構怪獸（一隻較急、一隻較穩），而且對應一種職業（例如科技做法師、醫療有牧師同聖騎士）。喺行情表撳報價放入下單票，輸入股數再買入或賣出；撳名稱或肖像可以打開檔案，睇招式、屬性，同埋紅升綠跌、可互動嘅 K 線（有收市價格線，滑過或拖曳會出十字線同開高低收）。

持倉表會列出股數、平均成本、現價、市值同浮動盈虧。帳戶列永遠顯示現金、總資產、今日盈虧（對開局價同今日已實現），以及總盈虧（總資產減開局 $1,000，包括出陣賞金）。戰鬥途中同浪與浪之間的空隙都可以下單；行情同時間喺空隙期間都會繼續行。沽空會分 8 浪自動出陣，打完有短暫空隙可以換倉。

撳「開始掛牌」之後進入無時限建倉：開市報價凍結，唔會跳價、唔會出推動行情嘅頭條，亦唔會出浪。至少持有 1 股之後撳「確認開市」，行情先會開始行，然後第一浪出陣。只買入唔會自動開市。之後每浪打完仍然係短空隙換倉，呢段期間行情會繼續行。怪獸陣亡會即時清倉，唔會套現。醫療牧師會為場上未倒下嘅隊友回血，聖騎士較坦並可加薄護盾；其他職業亦有看得見嘅抵擋、補給或爆發，但戰力仍然以持股 × 現價為核心。連續兩浪持有同一批股票（只改股數都算同一持倉），下一浪會有「過度集中」懲罰，當浪戰力減 15%。換走一隻或新買一隻就可以避免。八浪之內總資產達到 $3,500 即勝，破產或八浪結束則收市。首次達標會解鎖「保險」板塊（撐傘、全盾），下轉會出現喺行情板上。每隻怪都有虛構代號，名稱同肖像係對上市行業嘅二次創作，並非真實公司或商標。

升用紅色、跌用綠色（港式行情）。右上角 ♪ 可靜音。所有公司、產品同招式都係虛構，冇用真實商標，亦冇接真實行情。
