# 行情出陣 Ticker Beasts

用瀏覽器打開 `index.html`，或在本資料夾開一個靜態伺服器（例如 `python3 -m http.server 8766`），然後前往對應網址。

開局有 $1,000（局外可解鎖改為 $1,200）。撳「開始掛牌」之後進入無時限建倉：開市報價凍結，唔會跳價、唔會出頭條，亦唔會出浪。至少持有 1 股之後撳「確認開市」，行情先會開始行，然後第一浪出陣。只買入唔會自動開市。

撳圖示睇檔案，撳名稱或價錢揀嚟買賣。下單票用同一框裏面嘅 −、股數、＋同「最多」，再撳買入或賣出。戰鬥途中都可以調倉。

確認開市之後，大約每 5 秒跳一次價，每隔約 30 至 60 秒會有頭條帶動板塊。每浪打完會有約 25 秒換倉空隙，行情呢段時間會繼續行，並顯示倒數；準備好可以撳「下一浪」提早開打。改緊下單數量時，倒數完都唔會即刻出浪。戰鬥節奏較慢，隊友受重創會短暫慢下來。

層數向上爬，無固定完場浪數。第 5、15、25… 層係小 Boss，第 10、20、30… 層係大 Boss。打贏 Boss 之後三選一祝福（唔一定係現金或股票）。大目標係總資產 $8,000：賺夠可以勝出，亦可以繼續向下打。怪獸陣亡會即時清倉該股、唔會套現；其餘怪獸同現金可以繼續打。全軍覆沒或破產先完局，要重新掛牌，剩低現金唔可以再重組。達標或打到第 10 層會解鎖「保險」板塊，下轉會出現喺行情板上。

每個板塊有兩隻性格唔同嘅虛構怪獸，而且對應一種職業。板塊會輪動（主場／受壓），持倉職業最多同時觸發兩組連攜。戰力以持股 × 現價為核心，再按職業、輪動同連攜調整。醫療牧師會為場上未倒下嘅隊友回血，聖騎士較坦並可加薄護盾。連續兩浪持有同一批股票（只改股數都算同一持倉），下一浪會有「過度集中」懲罰，當浪戰力減 15%。

窄屏幕會用證券行式手機介面：帳戶列顯示現金、總資產、今日盈虧同總盈虧；底部分頁係行情、持倉同戰場；下單票 Sticky 喺分頁上面。闊屏幕仍然係行情同戰場並排。

升用紅色、跌用綠色（港式行情）。右上角 ♪ 可靜音。所有公司、產品同招式都係虛構，冇用真實商標，亦冇接真實行情。
